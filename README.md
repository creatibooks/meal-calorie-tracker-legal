# meal-calorie-tracker-legal

「プチカロリー」（食事カロリー記録アプリ）の公開法的文書（プライバシーポリシー等）を配信するための公開リポジトリです。

アプリ本体のソースコードは非公開の [meal-calorie-tracker](https://github.com/creatibooks/meal-calorie-tracker) リポジトリで管理しています。このリポジトリは、App Store Connect等に登録する公開URLを発行するためだけに存在します。

- プライバシーポリシー: GitHub Pages公開後、`https://creatibooks.github.io/meal-calorie-tracker-legal/privacy-policy.html` で公開予定
